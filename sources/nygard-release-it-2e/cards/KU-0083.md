# KU-0083: Production-oriented testing and failure simulation

- **book_id:** `nygard-release-it-2e`

## Purpose
Validate stability and recovery behavior under realistic load, dependency failure, deployment change, and user demand.

## Trigger
A system has high availability, high traffic, or costly failure consequences.

## Procedure
1. Define stability hypotheses and measurable success criteria.
2. Test representative load and saturation.
3. Inject dependency, process, network, configuration, and deployment failures in a controlled environment.
4. Verify alerts, fallback, recovery, and data correctness.
5. Promote proven experiments into regression checks.

## Checks
- Tests reveal failure modes before production.
- Recovery and user-visible behavior are measured.
- Experiments have a safety boundary and abort condition.

## Anti-patterns
- Testing only individual features under ideal conditions.
- Running destructive experiments without a hypothesis or rollback.
