# KU-0022: Value-first feature slicing and release planning

## Purpose
Deliver value and learning earlier by selecting small user-visible features before lower-value scope.

## Trigger
A product has more desired work than time or budget permits.

## Procedure
1. State the value sought by each candidate feature.
2. Split features into independently valuable slices.
3. Order slices by value, urgency, cost, and learning.
4. Release the smallest useful subset early.
5. Stop or redirect investment when marginal value falls.

## Checks
- Every planned item names user or business value.
- A release contains demonstrable user-facing capability.

## Anti-patterns
- Phase completion reported as value delivery.
