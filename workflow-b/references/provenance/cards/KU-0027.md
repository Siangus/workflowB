## Purpose
Scale delivery by organizing around end-to-end features and using a shared automated test suite as the coordination mechanism.

## Trigger
More than one team must deliver to a common product.

## Procedure
1. Establish cross-functional feature teams.
2. Integrate small changes frequently into the common product.
3. Run the shared automated checks before and after integration.
4. Fix failures introduced by the change before proceeding.
5. Add specialist infrastructure support only where feature teams cannot own it.

## Checks
- Every team can deliver an end-to-end feature.
- The common codebase remains green.

## Anti-patterns
- Sequential functional handoffs and separately green component branches.
