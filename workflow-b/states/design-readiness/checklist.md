# Design Readiness Checklist

Check each item with evidence; do not use percentage-complete as a substitute.

- [ ] Required design-package artifacts exist.
- [ ] arc42 exists and indexes context, constraints, strategy, building blocks, runtime, deployment, cross-cutting concepts, decisions, quality, risks, and glossary.
- [ ] Critical requirements trace to design and tests.
- [ ] Every traceability test ID exists in the test strategy catalog.
- [ ] Review decision is APPROVED or APPROVED_WITH_RISKS.
- [ ] Run `scripts/validate_project_design_package.py <design-package-path>` with no errors.

## Gates
- [ ] Requirements-to-acceptance review
- [ ] Architecture/contract review
- [ ] Consistency and recovery review
- [ ] Test strategy review
