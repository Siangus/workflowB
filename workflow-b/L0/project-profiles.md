# Project Profiles

## Exploratory Iterative

Use for uncertain product work with short feedback cycles. Load just-in-time requirements, value slicing, prototypes, lightweight architecture, and frequent acceptance evidence.

## Complex Domain

Use when business language differs across functions or domain rules interact heavily. Load bounded contexts, ubiquitous language, context maps, aggregate invariants, and domain-event methods.

## High Assurance

Use when safety, regulation, contracts, auditability, or failure cost is high. Strengthen baselines, traceability, quality scenarios, independent review, security, recovery, and release evidence.

## Distributed High Concurrency

Use when traffic spikes, shared state, asynchronous messages, or multi-node failure matter. Load performance, consistency, reliability, observability, concurrency, idempotency, and failure-testing modules.

## Legacy Evolution

Use when changing an existing system with incomplete tests or implicit rules. Load characterization tests, compatibility, migration, architecture debt, and incremental replacement methods.
