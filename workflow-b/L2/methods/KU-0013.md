# KU-0013: Test case design

**Type:** `method`
**Lifecycle:** `verification`
**Trigger:** Complex/high-risk logic.

## Purpose
Combine structural and behavioral techniques for risk coverage.

## Procedure
1. Model behavior.
2. Apply boundaries/equivalence.
3. Add path/branch tests.
4. Add negative cases.
5. Prioritize by risk.

## Checks
- Every case has expected result.
