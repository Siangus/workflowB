# KU-0008: Configuration control

**Type:** `method`
**Lifecycle:** `governance`
**Trigger:** Multiple contributors or release obligations.

## Purpose
Control versions, baselines, changes, builds, audits, and status.

## Procedure
1. Identify items.
2. Control branches.
3. Baseline artifacts.
4. Assess impact.
5. Audit releases.

## Checks
- Release maps to approved sources.
