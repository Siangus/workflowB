# KU-0012: Layered design

**Type:** `method`
**Lifecycle:** `design`
**Trigger:** Nontrivial approved scope.

## Purpose
Design data, architecture, interface, UX, and component logic coherently.

## Procedure
1. Design data.
2. Map architecture.
3. Design interfaces/UX.
4. Specify components.
5. Review traceability.

## Checks
- Requirement maps to design or backlog.
