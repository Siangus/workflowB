# KU-0080: Security as an ongoing production process

**Type:** `principle`
**Lifecycle:** `architecture`
**Trigger:** The system handles user data, privileged operations, external input, or third-party dependencies.

## Purpose
Treat security, data protection, least privilege, and vulnerability response as continuous responsibilities.

## Procedure
1. Identify sensitive data and trust boundaries.
2. Apply least privilege and secure secret handling.
3. Validate input and protect data integrity.
4. Monitor and respond to suspicious behavior and vulnerabilities.
5. Review security after changes and incidents.

## Checks
- Sensitive operations have authorization and audit evidence.
- Secrets are not embedded in code or logs.
- Vulnerability response has an owner and path.
