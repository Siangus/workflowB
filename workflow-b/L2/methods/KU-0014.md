# KU-0014: Verification strategy

**Type:** `method`
**Lifecycle:** `verification`
**Trigger:** Feature or release candidate.

## Purpose
Sequence unit, integration, validation, system, and regression testing.

## Procedure
1. Define unit/integration approach.
2. Verify scenarios.
3. Add performance/security/recovery.
4. Automate regression.
5. Set exit criteria.

## Checks
- Blockers triaged.
