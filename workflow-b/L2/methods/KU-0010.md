# KU-0010: Requirements elicitation

**Type:** `method`
**Lifecycle:** `requirements`
**Trigger:** Inception, scope change, ambiguity.

## Purpose
Turn needs into prioritized verifiable requirements and acceptance criteria.

## Procedure
1. Elicit scenarios.
2. Separate need and solution.
3. Prioritize conflicts.
4. Write testable requirements.
5. Review completeness/testability.

## Checks
- Each requirement has verification method.
