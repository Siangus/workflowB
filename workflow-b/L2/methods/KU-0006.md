**Type:** `method`
**Lifecycle:** `planning`

## Purpose

## Procedure
1. Define milestones.
2. Refine tasks.
3. Model critical path.
4. Allocate buffer.
5. Track output-based progress.

## Checks
- Critical path known.
- Variance triggers action.
