# KU-0007: Quality assurance

**Type:** `method`
**Lifecycle:** `quality`
**Trigger:** Before costly implementation or release.

## Purpose
Prevent and remove defects through reviews, standards, metrics, and correction.

## Procedure
1. Set quality goals.
2. Use entry/exit checklists.
3. Hold focused review.
4. Log defects.
5. Track escapes.

## Checks
- Findings have owner.
